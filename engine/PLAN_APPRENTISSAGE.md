# Plan d'apprentissage du moteur : ce qui est appris, ce qui reste

Règle : un sujet passe à « appris » seulement quand une méthode a été lue dans une source avec son contenu (pas seulement une liste de liens), ET testée par un rendu contrôlé. Les licences ne bloquent pas l'apprentissage ; elles sont vérifiées avant toute publication.

| Sujet | État | Ce qui manque |
|---|---|---|
| Animation de marche, course, coups (Mixamo, procédural) | Appris et testé | Mouvements plus variés, pieds collés au sol |
| Victoire, chute, mise au sol | Appris et testé (mesure, plan dédié) | Chute plus naturelle (bras, tête) |
| Son : bruitages synthétisés, calage à l'image | Appris et testé (mesure) | Qualité sonore à juger à l'oreille |
| Mesure dans le monde 3D, projection à l'image | Appris et testé | - |
| Caméra qui vise un point (Track To), plans liés aux marqueurs | Appris et testé | Composition de plans (règles de cadrage) |
| Rigify sur un nouveau maillage | Procédure lue (guide Neural4D) | Test sur corps de test |
| Peau réaliste (subsurface, textures) | Méthode lue, valeurs absentes | Balayage de valeurs par rendus |
| Visage, formes-clés (ARKit) | Principe lu en résumé | Test de quelques formes |
| Cheveux (particules, courbes, cartes) | Liste de sources seulement | Lecture du contenu, test |
| Cape, tissu, vêtements (simulation de tissu) | Liste de sources seulement | Lecture du contenu, test |
| Épée : retrait de la main, fourreau, prise | Liste de sources seulement | Lecture, test de parentage à une main |
| Interaction assise, manger, objet (IK des pieds, pose assise) | Liste de sources seulement | Lecture, test de pose assise |
| Interaction avec le décor 3D | Non lu | À faire |
| Effets magiques (lueur, particules, volumétrie) | Liste de sources seulement | Lecture, test d'une lueur |
| Modélisation d'objets et d'armures (hard surface, bevel) | Liste de sources seulement | Lecture, test d'une épée |
| Composition de caméra (types de plans, focales) | Liste de sources seulement | Lecture, test sur une séquence |
| Pose et squelette (contrôle d'articulations, limites) | Non lu | À faire |

## Conclusion
Le moteur n'a pas encore assez appris pour une animation premium. Il sait faire une cinématique simple avec des personnages de base, des effets sonores synthétisés et une caméra contrôlée. Les sujets listés ci-dessus demandent chacun une lecture et un test.
